================================
Custom Website Slides Quiz Modal
================================

This module customizes the quiz result modal in the Odoo eLearning (website_slides) module.

It simplifies the modal by:
- Removing the success image
- Removing XP (karma) display
- Removing progress bar and motivational messages
- Displaying only a centered message: "Section completed"

Configuration
=============
No configuration is needed.

Usage
=====
1. Install the module.
2. Complete any quiz in eLearning.
3. The result modal will now display a simplified, centered confirmation message.
