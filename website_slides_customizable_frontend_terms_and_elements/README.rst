===================================================
eLearning: Customizable Frontend Terms and Elements
===================================================

* Gives options to hide certain elements from eLearning pages
  that may not always be relevant
* Also gives options to swap the used terminology to certain 
  places where it can not be done with the website editor
  

Configuration
=============
* Go to Website -> Configuration -> Websites -> your website
  to see the website-specific settings in the new "eLearning
  terms and elements" section
* Go to eLearning -> Courses -> your course to see
  course-specific settings in the Options tab
* Note that some terms you can simply edit with the website editor,
  e.g. the "My courses" and "Most popular courses" texts in /slides.

Usage
=====
* Just browse the frontend elearning pages

Known issues / Roadmap
======================
* Modifications target the "Training" layout currently. For 
  "Documentation" layout additional xpath is needed.
