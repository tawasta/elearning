=================================================
eLearning: Get Invite Sender From E-mail Template
=================================================

* Makes the course "Add Attendees" and "Invite" email wizards respect the
  "From" address set on their mail template, overriding the core behaviour
  of simply using the sending user's email address.

Configuration
=============
* Set the desired sender for "Elearning: Add Attendees to Course" and 
  "Elearning: Promotional Course Invitation" email templates

Usage
=====
* Just add / invite people from the course form view.
