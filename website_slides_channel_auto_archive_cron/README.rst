========================================
eLearning: Auto-archive Cron for Courses
========================================

* Enables setting a date when the course will be unpublished and archived
  

Configuration
=============
* In the Course form view, set the new "Automatically Archive the Course On" field 
* Finetune the cron interval if needed. Default is every 3 hours
